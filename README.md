# Better Orbital Traders (RimWorld)

**Better Orbital Traders** Better Orbital Traders is a massive buff and re-balance to vanilla orbital traders. Better Orbital Traders additionally adds 3 new orbital trader types, including an Orbital Scrapyard which will buy ANYTHING. Get rid of your junk!

The quantity of silver carried by base game orbital traders has been substantially increased (within reason), and their stock quantities have been re-balanced to demonstrate the massive size of these ships and the quantity of goods they carry. This change makes vanilla orbital traders more significant for late game colonies and wealthy players, and gives early game players expanded options.
